# Third-party components

Everything in this repo, or fetched by its scripts, that someone outside the
project made: name, version, licence and source. A licence text that has to
travel with a component sits next to it. coach itself is GPL-3.0-or-later
([docs/decisions.md](docs/decisions.md#licence)); every component
that ships in the app has to be compatible with it
([docs/rules-core.md](docs/rules-core.md)).

- **MediaPipe Pose** ships its JavaScript, WebAssembly, graph data, packed
  detector assets and the full landmark model (`pose_landmark_full.tflite`).
  The heavy and lite model variants and the source maps are left out,
  because coach uses `modelComplexity` 1. The package's own `package.json` is
  kept, and `src/pose/vendor/pose-assets-manifest.json` records each file's
  size and SHA-256. This legacy package is pinned on purpose; the newer Tasks
  Vision API is where MediaPipe went next. Docs:
  <https://chuoling.github.io/mediapipe/solutions/pose.html>.
- **three.js** was copied from the project's existing `src/vendor/` copy into
  `src/squat/vendor/` for the Movement Lab, which serves it from its own
  route.
- **BodyParts3D**: the build is reproducible with `scripts/build_anatomy.py`
  from the pinned source meshes (ATTRIBUTION.md says how).
- **The Movement Lab's demo session** is generated by `demoSession()` and
  holds no recorded person. Its movement heuristics and rigging are the
  project's own code.

  `ultralytics/assets` repo the weights come from declares AGPL-3.0. None
  of them names `yolov8s.pt` itself, so treat the weights as AGPL-3.0
  (checked 2026-10-31). This is why YOLOv8 stays on the dev server.

## Data

Not code, and not shipped in the app; listed so a release check sees it.

- **The fixture tracks and goldens** (`tests/fixtures/global/`,
  `tests/golden/global/`) are keypoints computed from third-party clips. The
  clips themselves are not committed; where each came from is in
  [tests/fixtures/README.md](tests/fixtures/README.md#videos).
- **The `athlete-a` limb profile** holds four ratios measured from a press
  photo, which is not in the repo.
