# logo/

The coach³ logo, by nordmu (2026), licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); the full
text ships in the app as `app/licences/CC-BY-SA-4.0.txt`. This covers the
files below and every icon rendered from them; the code stays
AGPL-3.0-or-later.

- `coach-cubed.afdesign`: the editable source (Affinity Designer); edit it,
  then export the two layers below.
- `coach-cubed_back.svg` and `coach-cubed_front.svg`: the app icon's two
  layers (the ground and the symbol) on Android's 108-unit adaptive-icon
  grid. `node app/tools/make-icon.mjs` renders every icon from them: the
  PWA's (`app/icons/`), the APK's launcher and splash icons, and
  `coach-cubed-512.png` here for F-Droid and GitHub releases.
- `coach_logo_v1.png`, `coach_logo_v1_cropped.png`: the old header logo of
  the frozen old page; not part of the above.

What the logo has to survive and what is still open:
[docs/branding.md](../docs/branding.md#the-logo).
