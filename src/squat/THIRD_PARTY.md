## Anatomy, interface and movement rules

The model uses 337 BodyParts3D anatomical surfaces under the current CC BY 4.0
database licence. See [full attribution and adaptation record](../anatomy/models/ATTRIBUTION.md).
Source names, IDs and hashes are retained in `../anatomy/models/body.json`.
The source atlas is static; this prototype supplies approximate regional skinning.
It replaces the previous procedural model.

The synthetic demonstration is generated by `demoSession()` and contains no
recorded person. Movement heuristics and rigging are local prototype code.
The original project files retain their existing authorship and terms.
