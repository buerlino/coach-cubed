# d57: the layout check measures Q1's failed panels (dirac, sonnet, branch `wp/dirac-q1-layout-failed`)
**Why:** the layout check (app/tools/layout-check.mjs, d25) walks Q1 only while a job runs and once it is done. Q1's
failed panels, "No person found" and the unreadable video with "Pick another video" (d51, d56), are never drawn there,
so their buttons' 44 px and the panel's fit at each size are not measured (d51's report, "Needs a decision" 1: "the
replay engine can't make a job find nobody without engine work"; nordmu said yes on 2026-11-02).
**Read:** app/tools/layout-check.mjs; app/page-test/replay.mjs; app/page-test/boot.mjs; app/tools/page-test.mjs;
app/tools/assemble.mjs; app/src/analysis/job.mjs; app/src/ui/screens/Q1.mjs; app/src/ui/analysing-model.mjs;
tests/app/page-test.test.js. The bundle cuts at 2000 lines, so read app/README.md's "The page test", "A4 and the
responsive check" and "Q1, analysing" sections yourself.
1. A way for the test build to end a job with "No person found": a committed fixture or a replay mode in which the
   job's track keeps no frames (job.mjs throws NoPersonError when `track.meta.tracks.kept_frames === 0`), and a way to
   end one as an unreadable video (a clip the frame source refuses). Test build only: the shipped `dist/` stays as it is
   (assemble.mjs without `--test` copies none of it), and the page test's own run is unchanged.
2. layout-check.mjs walks `Q1 (No person found)` and `Q1 (unreadable)` at every size it checks, with the checks every
   other screen gets (nothing cut off or overflowing, each button's touch target at least 44 px).
3. A Node test (tests/app/page-test.test.js or a new one beside it) pins the new mode: the job it starts fails with the
   problem kind `no-person`, resp. `unreadable`.
4. app/README.md's "The page test" and "A4 and the responsive check" name the two new screens and how they are made.
**Done when:**
- `npm --prefix app run check:layout` passes and its output lists both new screens at every size;
- `node app/tools/assemble.mjs` (without `--test`) assembles the same files as on phase-0;
- `npm test`, `npm --prefix app test`, `npm --prefix app run test:page` and the Python tests pass.
