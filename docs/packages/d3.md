# d3: the app's frame (dirac, sonnet, branch `wp/dirac-app-frame`)
**Why:** Phase 5 builds the new app fresh as static files (decisions.md, "What 0.1.0 is"), and every later package needs its
folder, its look, its build and its tests. There is no `app/` yet. The architecture is decided in docs/app-plan.md: `app/`,
plain ES modules with no build for our own code, the screens in Preact with htm (D1), an assembled `app/dist/`.
**Read:** docs/app-plan.md ("The architecture", "The build", "The pieces"); docs/ui-design.md ("The screens", "The look",
"Keeping the UI maintainable"); design/mockups/Main.dc.html (H, for the look); tests/paths.test.js; README.md ("Layout");
THIRD_PARTY.md (its format); tests/README.md.
**Red first:** yes
1. Tests first, in `tests/app/`: `flow.test.js` for the flow's state machine (the states home, import, mark, queued,
   result, settings, plus live and replay for milestone B; the transitions milestone A's flow needs, H → import → mark →
   queued → result and back to H; an illegal transition throws; listeners hear each change); `assemble.test.js` for
   `app/tools/assemble.mjs` into a temporary folder (index.html, the manifest, the vendored files, `diagnostics.js` and
   `src/track/` where the app's imports reach them, `files.json` with every file copied and a version hash, and the run
   with `app/vendor/tfjs/` and `app/models/` absent). Extend tests/paths.test.js's `SCANNED` to `app/` (not
   `app/vendor/`, `app/dist/`, `app/android/` or `node_modules/`). They fail on phase-0. Every test in `tests/app/` runs
   in a fresh worktree, which has neither gitignored folder.
2. `app/` as app-plan.md's tree has it, only the parts this package needs: `index.html` (relative paths only),
   `manifest.webmanifest` (name and short name the placeholder "coach" while question 10 is open, `start_url` and `scope`
   `./`, display standalone, the ground colour, a plain generated icon recorded as a placeholder), `src/main.mjs`,
   `src/flow/` (a plain module, no Preact), `src/ui/` (the app shell and one placeholder component per screen ID, chosen
   by the flow's state; screens never call each other), `src/styles/tokens.css` and `base.css` (every value from
   ui-design.md "The look": the colours, the status colours with their words, the type, the spacing, 44 px touch
   targets; dark only).
3. Vendor, pinned, each beside its licence text: Preact 11.1.1 (MIT) with its hooks, and htm 3.1.1 (Apache-2.0), ES
   modules from their npm tarballs (`npm pack`). Check first that the version exists (`npm view preact versions`); if
   11.1.1 isn't there, pin the newest 11.x and say which. Preact's hooks import `preact` by bare name: an import map in
   index.html with relative URLs keeps the pin; htm's `preact/standalone` carries htm's own build of Preact instead, so
   choosing it makes that build the pinned version. Say which and why in app/README.md. Barlow and Barlow Condensed (SIL
   OFL 1.1) as woff2, only the weights the mockups load (their Google Fonts links), with OFL.txt; `@font-face` with
   relative URLs.
4. THIRD_PARTY.md: its section "In the app (served to the browser)" lists the old page's components (MediaPipe Pose,
   three.js, BodyParts3D). `git grep` the repo for that section's anchor first, then retitle it "In the old page (frozen, not in
   0.1.0)" and fix every link to it. Add a section "In the new app (`app/`)" with the rows for Preact, htm and the
   fonts; every later package adds its rows there.
5. `app/tools/assemble.mjs` (Node, no dependencies): `app/` without `tools/`, `android/`, `dist/` and `node_modules/`
   into `app/dist/`, plus `diagnostics.js` and `src/track/` (they stay in `src/`: the old page serves them), placed so
   the same relative imports work in the repo (Node tests, dev) and in `dist/` (PWA, Capacitor). `app/vendor/tfjs/` and
   `app/models/` (gitignored, made by s6) are copied when present; when absent, assemble prints a line and goes on.
   `dist/files.json`, for the service worker (c19), lists only what was copied. `app/tools/serve.mjs` (Node, no
   dependencies): `app/dist/` on a port option, no COOP/COEP, the right types for `.mjs`, `.webmanifest`, `.woff2` and
   `.wasm`.
6. `app/package.json`: private, `"type": "module"`, no dependencies yet, a `test` script running `tests/app/` with
   `node --test` (the pipeline runs `npm --prefix app test`). `.gitignore` entries for `app/dist/`, `app/models/`,
   `app/vendor/tfjs/` and `app/node_modules/`.
7. Docs: `app/README.md` (what's where, the commands, how imports reach `diagnostics.js` and `src/track/`, the vendored
   files), a Layout row in README.md, tests/README.md's table.

- the assemble test and every test in `tests/app/` pass in a fresh worktree without `app/vendor/tfjs/` and `app/models/`;
- the flow and assemble tests pass, and `npm test`, `npm --prefix app test` and the Python tests pass.
