# s39: the headless API gives A2's scoring lines and zones (schrödinger, opus, branch `wp/schroedinger-a2-scoring`)
**Why:** A2 shows a cue's plot against its zones and a "How it's scored · provisional" block (docs/ui-design.md, A2;
design/mockups/CueDetail.dc.html: good, watch and work on bands at the elbow lead's +5 % and −5 %), and d18 may show only
diagnostics.js's words and numbers. Neither is in s4's headless API:
- the block is each cue's `transparencyLines(res, samples, ctxExtra)`: the phase, the measurement, the bar axis, the time
  smoothing, the caveat with the provisional bands, the notes, as the old panel lists them under the plot
  (`drawPanels()`). s4 left them out (s4's report, item 5: HTML that needs the smoothing, the scale and the axis). Since
  s35 the view carries the smoothing it was scored with (contract 4's `smoothing`), so the "Time smoothing" line can say
  the truth (s11's report, item 1);
- the zones are each cue's verdict thresholds (the elbow lead's `ELBOW_GOOD` and `ELBOW_WARN`), which only its own
  `verdict()` reads; the old panel's `drawChart()` draws no zones.
**Read:** src/diagnostics.js by section (`grep -n '^// ---' src/diagnostics.js`: the headless API's comment above
`const Diagnostics`, `drawPanels()` and `redrawAll()` in "rendering", `axisNote()`, `WORST_RULES`, and each cue's
`verdict` and `transparencyLines`); tests/app/diagnostics-headless.test.js; app/src/contracts/cue-view.mjs
(`VERDICT_VALUE`, `VERDICT_STATUS`, `smoothing`); app/src/scoring/score.mjs; .claude/skills/lifting-diagnostic/SKILL.md.
