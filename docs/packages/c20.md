# c20: the Capacitor shell (curie, sonnet, branch `wp/curie-capacitor`)
**Why:** 0.1.0 ships as a PWA and as an APK from one web app (rules-core.md); the spike's throwaway shell showed
Capacitor 8.5.3 running the engine in the WebView. The app needs its own shell around `app/dist/`. Debug APKs only until
the name, the package ID (question 10) and the signing key's holder (6.2) are settled.
**Read:** spike/webview-shell/README.md; spike/webview-shell/build.sh; spike/webview-shell/package.json; app/README.md;
app/package.json; docs/app-plan.md ("The pieces"); THIRD_PARTY.md.
1. `app/android/` from `npx cap add android`, with `@capacitor/core`, `cli` and `android` 8.5.3 (MIT) pinned in
   app/package.json; `capacitor.config.json` with `webDir` `dist`, a placeholder app ID named as such in app/README.md,
   the name "coach"; no camera permission before milestone B.
2. `app/tools/build-apk.sh`: assemble, `cap sync`, Gradle niced to one worker (the laptop is shared), a debug APK,
   never signed for release; build outputs gitignored, the generated project committed.
3. Check in the WebView what the app needs: file import through `<input type="file">`, WebGL, OPFS and `persist()`; the
   service worker isn't needed inside the APK: register it only where it helps, and say what you chose.
4. On the Fairphone (docs/pipeline.md, "The phone": its lock, `adb -s 4d42e62f`): install, open, import the test clip
   from `tests/app/clips/`, report what worked, uninstall.
**Done when:**
- a clean checkout builds the debug APK with the script, and it opens on H on the Fairphone;
- Capacitor is in THIRD_PARTY.md;
- `npm test`, `npm --prefix app test` and the Python tests pass.
