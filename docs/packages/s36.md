# s36: a lift without a lift window says so (schrödinger, opus, branch `wp/schroedinger-no-lift-window`)
**Why:** the lift window is the barbell's (diagnostics.js `liftWindow()`: the bar below knee height, then a held
lockout), but computeResults() runs it for every set, so a lateral raise gets "The bar never sits below knee height in
this clip, so there is no start of the lift to mark." as its window's reason (s5 and s11's reports; the example in
app/src/contracts/cue-view.mjs shows it). That is the engine's word, but not an honest one: a lateral raise has no bar.
nordmu decided on 2026-11-02: each set in diagnostics.js says whether it has a lift window, and a lateral raise gets none
and no error. The comment above `const lift = liftWindow(...)` in computeResults() still says this is the old page's
call (PAGES in `src/`'s app.py): this package moves it into the registry.
