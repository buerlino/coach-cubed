# c48: the app tests leave no temp folders behind (curie, sonnet, branch `wp/curie-test-tmp`)
**Why:** on 2026-11-02 `/tmp` held 10,392 folders, 9.3 GB, left by the app tests since that morning. The root disk
was at 92% with 5.9 GB free, and the night's runs add gigabytes (each run tests on several rounds), so a full disk would
have stopped the pipeline next; they were deleted by hand at 19:55. The leaks, by prefix and count: from
tests/app/assemble.test.js's `tmp(name)` (:19) `coach-tree-` 2943 and `coach-a/b/c/d/absent/present/files/imports/
real/shared/only/refuse/hash/twice-` 385 each, `coach-shipped/debug/fake-debug-` ~248 each (`files`, `imports`, `real`
and `shared` 1.6 GB each); tests/app/serve.test.js `coach-serve-` 1134 (`withServer`, :26, no cleanup);
tests/app/sw.test.js `coach-swstamp-` 153 (:242, no cleanup); tests/app/settings.test.js `coach-d24-` 3. c47 (merged
`c3cf06f`) already removes the browser tools' profiles.
