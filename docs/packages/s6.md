# s6: TF.js and pose-detection built from source (schrödinger, opus, branch `wp/schroedinger-tfjs-source`)
**Why:** The pose runtime that ships is built from source (rules-core.md, "Licence-compatible dependencies"), and the app
bundles TF.js from the tags' TypeScript, not npm's built `dist/` (nordmu, 2026-11-01; pose-spike.md in `docs/`, sections
"F-Droid (step 3.8, on paper)" and "Maintaining TF.js ourselves", from line 389). The spike's build bundles npm's output.
**Read:** spike/pose-bench/build-tfjs.mjs; spike/pose-bench/fetch-models.sh; spike/pose-bench/package.json;
spike/pose-bench/lib/engines.mjs (the MoveNet path); docs/app-plan.md ("The build"); THIRD_PARTY.md; app/README.md;
app/package.json.
1. `app/tools/build-tfjs.mjs`: clone tensorflow/tfjs at tag `tfjs-v4.22.0` and tensorflow/tfjs-models at
   `pose-detection-v2.1.3`, each checked against a pinned commit, into a cache outside the repo
   (`$XDG_CACHE_HOME/coach/`, by default `~/.cache/coach/`: the root `npm test` runs test files anywhere inside the tree);
   generate the converter's op lists as tfjs's own build does; bundle with esbuild (pinned in app/package.json, with its
   lock file) from the TypeScript through the tag's root tsconfig path map: tfjs-core, the converter, the WebGL and
   WebGPU backends (pose-detection imports WebGPU), the CPU backend (for s7) and pose-detection with MoveNet only,
   `@mediapipe/pose` stubbed as in the spike. Out: `app/vendor/tfjs/` (gitignored), one ES module per backend, plus the
   licences.
2. Where esbuild can't take a construct (`const enum` across files is the known suspect), a minimal patch under
   `app/tools/patches/`, applied by the script and named in the report with the reason. Apache-2.0 §4(b): each patched
   file gets a notice that we changed it, in the bundle's banner and in app/README.md.
3. `app/tools/fetch-models.sh`: MoveNet SinglePose Thunder v4's TF.js weights from the spike's pinned source, checked
   against their SHA-256, into `app/models/` (gitignored).
4. THIRD_PARTY.md's section "In the new app (`app/`)": TF.js 4.22.0 and pose-detection 2.1.3 (Apache-2.0, built from
   source at the pinned commits), MoveNet Thunder's weights (Apache-2.0, the source), esbuild (MIT, build only).
   app/README.md: the commands, the cache, the patches.
5. **Split point.** If the run nears its 3-hour limit, stop after the clones, the op lists, the core, CPU and converter
   bundles and fetch-models.sh, with a clean commit; the WebGL, WebGPU and pose-detection bundles then go under "Not
   done" and run as s6b.
**Done when:**
- with an empty cache, `node app/tools/build-tfjs.mjs` builds every bundle, and a second run reuses the cache;
- the WebGL bundle loads and creates a MoveNet Thunder detector from `app/models/` (say how you checked);
- no clone or cache sits inside the repo; the report lists the bundle sizes beside the spike's and every patch;
- each patched file's notice is in its bundle's banner and in app/README.md;
- after a split (step 5), the report says so, the first line holds for the bundles built, and the detector check is s6b's;
- `npm test`, `npm --prefix app test` and the Python tests pass.
