**Why:** the reports of s9, s10, s11 and s12 each asked for a change to a contract (s5's files in
`app/src/contracts/`), and nordmu approved all four on 2026-11-02 as one package, run before the screens build on them:

  adapter returns it beside the view, so result.json loses it);

  the cut read and opened.
