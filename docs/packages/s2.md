**Why:** `docs/backlog.md`, Bugs: `scripts/sync_clipper_fixtures.py` accepts only 2-digit attempt numbers.
`CLIP_NAME_RE` (line 83) has `(?P<idx>\d{2})`, but clipper names its clips with
`f"{session}_{i:02d}_{hh}h{mm:02d}m{ss:02d}s_{c['result']}.mp4"` (weightlifting-clipper `src/cut.py:19`, a sibling
repo of the main checkout on this laptop). From attempt 100 on, that name has three digits. `src/app.py`'s train tab
accepts `\d+`. This is the likely cause of the 30 skipped clips in `docs/dataset-stats.md`.
**Read:** `scripts/sync_clipper_fixtures.py` (lines 60–100 and `main()`); `tests/test_launchers.py` (how a test loads a
script with `runpy`); `docs/clipper-pipeline.md`; `docs/dataset-stats.md` (the skipped clips).
