# c52: the tools' browser leaves no org.chromium.Chromium folders in /tmp (curie, sonnet, branch `wp/curie-chromium-tmp`)
**Why:** c48's report: headless Brave still leaves `org.chromium.Chromium.*` folders in the temp folder. On 2026-11-02
at 21:30 there were 1,431 of them in /tmp (363 MB), 1,269 made in the two hours before, while d25's layout check ran
112 browser checks. Each holds `SingletonCookie` and `SingletonSocket`: Chromium's singleton folder for a profile,
removed on a clean exit but left when the browser is killed. app/tools/browser.mjs (c47) kills the whole process tree,
which is right for the leak c47 fixed, so the folder stays. nordmu decided on 2026-11-02: fix it in the tools' browser,
laptop only.
**Read:** app/tools/browser.mjs; tests/app/browser.test.js; tests/app/tmp-clean.test.js; app/tools/layout-check.mjs;
app/tools/page-test.mjs. The bundle cuts at 2000 lines, so read app/README.md's "The tools' browser" and "The tests"
yourself (both past line 1,300 of about 1,400).
**Red first:** yes
1. Tests first, failing on phase-0: launching and closing a browser through browser.mjs leaves no new
   `org.chromium.Chromium.*` entry in `os.tmpdir()`, both on a normal `close()` and when the browser was killed. Count
   only entries the test's own browser made (compare before and after, or give the browser its own temp folder), so a
   parallel run elsewhere on the machine can't make it flaky.
2. The fix in browser.mjs. One way: give each browser its own temp folder (`TMPDIR` in the child's environment, inside
   the folder that already holds the profile), so the singleton folder lands there and goes with it on `close()`.
   Check first that Brave honours `TMPDIR` for it. If it doesn't, find the folder through the profile's
   `SingletonSocket` link and remove it on close. Either way, nothing outside the browser's own folders is touched.
3. In the report, say whether every tool in tests/app/browser.test.js's list now leaves nothing behind (run the page
   test and the layout check once, compare /tmp before and after).
**Done when:**
