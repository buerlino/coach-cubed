# s1: a fixture without a diagnostics set fails loudly instead of scoring as snatch (schrödinger, sonnet, branch `wp/schroedinger-fixture-set`)
**Why:** `docs/backlog.md`, Bugs: "A fixture without a `diagnostics` field is silently scored as snatch". Three places
fall back to snatch, `manifest[slug].diagnostics || 'snatch'`: `tests/diagnostics.test.js:34`, `tests/track.test.js:26`
and `tests/update_golden.js:29`. The global manifest's `example/athlete-a-trim` has no field and is scored as snatch
through that fallback. A lateral-raise fixture added without the field would get snatch goldens, and no test would
notice. This is also the pipeline's first real run (plan step 4.4), so it is small on purpose.
**Read:** `tests/fixtures.js`; `tests/diagnostics.test.js` (lines 1–60); `tests/track.test.js` (lines 1–40);
`tests/update_golden.js`; `tests/loadDiagnostics.js`; `src/track/lift-window.mjs` (`scoreTrack`, its empty-track
branch); `tests/fixtures/README.md` (the layout, the manifest, where `athlete-a` comes from);
`tests/fixtures/global/manifest.json`; `docs/fixture-data-contract.md` "`manifest.json`".
**Red first:** yes
1. **Tests first,** a new `tests/fixtures.test.js`:

     know; each message names the slug;

   "knows" means: after `setPage(name)`, `computeResults({}, meta, '0').results` has at least one cue id. That is the
   trick `scoreTrack` uses for an empty track. Don't change diagnostics.js.

   is a snatch: `tests/fixtures/README.md`, `docs/fixture-data-contract.md`, and its golden's cue ids
   (`tests/golden/global/example-athlete-a-trim.json`). Its golden must not change. If the sources disagree, stop and
   report it under "Needs a decision".
